여는 괄호를 스택에 쌓고 닫는 괄호가 올 때 스택 맨 위와 짝을 맞춰 pop 하며, 끝에 스택이 비었는지로 균형 여부를 판정하는 과정을 단계별로 보여주는 인터랙티브 시각화

풀이 시각화 — 스택으로 괄호 짝맞추기

여는 괄호는 스택에 쌓이고(push), 닫는 괄호는 맨 위와 짝을 맞춰 빠집니다(pop). 프리셋을 고르거나 직접 입력해 단계를 넘겨 보세요.

한 장면으로 기억하기: 여는 건 스택에 쌓고(push), 닫는 건 맨 위와 짝 맞춰 빼고(pop), 다 돌고 스택이 비면 YES.
실패는 셋 — 닫는데 스택이 비었거나, 맨 위와 종류가 안 맞거나, 다 돌았는데 스택이 안 비었거나(열린 채 남음). 마지막 하나가 이 풀이에서 놓쳤던 자리입니다.
