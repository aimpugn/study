슬라이딩 윈도우의 지출을 count 배열로 세고, 값 0부터 누적해 k번째(중앙값)를 찾고, 윈도우가 한 칸 움직일 때 count를 두 칸만 갱신하는 과정을 단계별로 보여주는 인터랙티브 시각화

풀이 시각화 — 정렬 없이 count로 중앙값 찾기

윈도우의 지출을 값별로 세고(count), 값 0부터 누적해 가운데(k번째)에 처음 닿는 값이 중앙값입니다. 정렬을 안 만들고도 같은 답이 나오는 걸 단계로 따라가 보세요.

한 장면으로 기억하기: count 배열을 값 0부터 읽는 것 = 정렬된 배열을 처음부터 읽는 것. 그러니 정렬을 만들지 않고도, 누적 개수가 처음 k(가운데 번째)에 닿는 값이 곧 중앙값입니다.
그리고 윈도우는 한 칸씩만 움직이니, 매번 새로 세지 말고 나가는 날 -1, 들어오는 날 +1만 갱신하면 됩니다.
또는 직접(지출, 쉼표):
지출 일별 (파랑 테두리 = 현재 윈도우, 빨강 = 오늘 판정할 날)
count 배열 (칸 = 값, 숫자 = 그 값이 윈도우에 몇 번)
