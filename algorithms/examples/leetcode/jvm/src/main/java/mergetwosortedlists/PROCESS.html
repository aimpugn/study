정렬된 두 연결 리스트를 하나로 병합하는 과정을, 두 리스트의 앞을 비교해 작은 쪽을 결과에 잇는 단계별 변화로 보여주는 인터랙티브 시각화

풀이 시각화 — 두 앞을 비교해 작은 쪽을 잇는다

두 정렬 리스트의 맨 앞만 비교해, 작은 쪽 노드를 결과 끝에 이어 붙입니다. 프리셋을 고르거나 직접 입력해 단계를 넘겨 보세요. 파랑 = 지금 비교하는 두 앞, 초록 = 방금 결과에 붙은 노드, 흐림 = 이미 가져간 노드.

한 장면으로 기억하기: 두 리스트의 앞 중 작은 쪽(같으면 list1)을 결과 꼬리에 잇고, 그쪽만 한 칸 전진한다.
핵심은 노드를 새로 만들지 않는다는 것. 노드는 이미 두 입력 안에 있으니 그 노드 자체를 이으면(splice) 공간이 O(1)입니다. 한쪽이 비면 남은 리스트를 통째로 잇습니다.
